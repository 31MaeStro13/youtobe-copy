# AGENTS.md: Инженерный регламент и правила разработки для ИИ-агентов

## 1. Архитектурный манифест
* **Проект**: Полнофункциональный микросервисный клон YouTube с асинхронным видеостримингом.
* **Стек**:
  * Backend: Python 3.12+, FastAPI (ASGI), SQLAlchemy 2.0 (async), asyncpg, Pydantic v2, Alembic.
  * Хранилище: MinIO (S3 API), поддержка Presigned URL (TTL) и HTTP Range requests (код 206).
  * Фоновые очереди: Celery + Redis + FFmpeg (генерация WebP превью, метаданные, HLS / faststart).
  * База данных: PostgreSQL 16 (индексы поиска, внешние ключи, каскады, RBAC).
  * Frontend: 7 экранов YouTube UI (темная тема, адаптивная сетка, плеер, кабинет автора, модерация).
  * Деплой: Docker Compose в одну команду (`docker compose up --build -d`) со встроенным авто-сидированием.

## 2. Ключевые правила разработки
1. **Zero-Guessing (Никаких гаданий)**: Любая логика строится строго на подтвержденных типах и спецификациях.
2. **Строгая типизация**: Полный отказ от нетипизированного кода. Только Pydantic v2 модели и SQLAlchemy 2.0 `Mapped[...]`.
3. **Безопасность (AppSec)**:
   * Пароли хешируются строго через Argon2 (`argon2-cffi`).
   * Авторизация по JWT (Access + Refresh).
   * RBAC на уровне dependency injection (`User`, `Moderator`, `Admin`).
   * Приватные видео доступны только владельцу или по временной подписанной ссылке (Presigned URL с TTL).
4. **Неблокирующий I/O**: Все операции с БД и S3 строго асинхронные (`async`/`await`). Тяжелые задачи FFmpeg — только в воркерах Celery.
